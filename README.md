📊 COVID-19 Dashboard (SQL + Tableau)
📝 #ProjectDescription

This project focuses on analyzing global COVID-19 data to uncover trends in infection rates, mortality, and vaccination progress across countries and continents. Using SQL for data cleaning and transformation, and Tableau for visualization, the project converts raw, unstructured data into an interactive and insightful dashboard.

The dashboard enables users to explore how COVID-19 spread over time, compare regions, and understand the impact of vaccinations on different populations.

🎯 #Objectives
Analyze global COVID-19 trends using real-world data
Compare infection and death rates across countries and continents
Track vaccination progress over time
Build an interactive dashboard for data-driven insights

⚙️ #ToolsUsed
SQL (MySQL) → Data cleaning, transformation, analysis
Tableau → Data visualization and dashboard creation
Excel → Data formatting and preparation
🔍 #KeyFeatures
📈 Global Trends Analysis
Daily total cases and deaths
Global death percentage

🌍 Country & Continent Comparison
Infection rate relative to population
Total deaths by region
💉 Vaccination Tracking
Rolling vaccination counts using window functions
Percentage of population vaccinated

📊 Interactive Dashboard
Filters by country and date
Dynamic visualizations for deeper insights

💡 #KeyInsights
Infection rates vary significantly when adjusted for population size
Some regions show high case counts but relatively lower death percentages
Vaccination rollout differs greatly across countries
Data normalization is essential for fair comparisons

🧠 #WhatILearned
How to clean and prepare real-world datasets using SQL
Applying advanced SQL techniques (joins, window functions, CTEs)
Transforming data into meaningful business insights
Designing dashboards that communicate data effectively

🚀 #Conclusion

This project demonstrates the ability to work with real-world data, perform structured analysis, and present insights through interactive visualizations. It highlights both technical SQL skills and the ability to communicate findings effectively—key skills for a data analyst role.
